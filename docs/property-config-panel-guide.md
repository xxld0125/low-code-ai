# 属性配置面板 - 用户指南

## 概述

属性配置面板是FlowBase低代码平台的核心功能，允许用户通过直观的界面配置组件属性。

## 主要功能

### 1. 基础属性配置
- 文本内容编辑
- 占位符设置
- 必填状态配置

### 2. 样式配置
- 尺寸调整
- 颜色选择
- 边距设置
- 对齐方式

### 3. 事件绑定
- 点击事件
- 提交事件

### 4. 高级功能
- 撤销重做
- 属性模板
- 自定义验证规则

## 快速开始

1. 选中组件
2. 在右侧属性面板中修改属性
3. 点击保存按钮应用更改

## 键盘快捷键

- `Ctrl/Cmd + Z`: 撤销
- `Ctrl/Cmd + Y` 或 `Ctrl/Cmd + Shift + Z`: 重做

## 故障排除

### 属性面板不显示
- 检查是否选中了组件
- 刷新页面重试

### 属性更改不生效
- 检查网络连接
- 确认点击了保存按钮

更多详细信息请参考完整文档。
